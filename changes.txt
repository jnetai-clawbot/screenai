Key Changes:
- Complete offline screenshot analysis with pattern-matching engine
- 6 analysis types: Error, Code, UI, Math, Form, General
- Room database for persistent searchable history
- Compose UI with Material 3 dark theme and neon accents
- Bottom navigation: Home, Analyze, History, Settings
- Image import via content resolver with local caching
- Clipboard copy, text share, and full report export
- GitHub Actions: debug APK on push, signed release on tag v*
- ARM64-only build targeting SDK 34
- Debug logger with file rotation at 5MB
