# Changelog

## [1.0.0] - Initial Release

### Added
- Screenshot import and analysis
- Error message detection and explanation
- Code block parsing and structure analysis
- UI element recognition (buttons, inputs, navigation)
- Math equation and formula interpretation
- Form field detection and analysis
- Text extraction (OCR simulation)
- Searchable analysis history with Room database
- Copy to clipboard functionality
- Share analysis as text
- Export results support
- Dark Material Design 3 theme with neon orange/pink accents
- Persistent debug logging with SA-xxx error codes
- GitHub Actions CI/CD for debug and release APKs
- ARM64-only builds
